# La Catrina

Original candy-rose hydraulic coupe authored from the supplied visual atlas. The standard GLB contains all textures, 13-inch chrome wire wheels with narrow whitewalls, four headlamps, six rear lamps, plum pleated benches, an X frame, two hydraulic pump circuits and four batteries.

Metres, +Y up, +Z forward. Root origin is ground level in the rest pose. Wheel nodes and separate steering/spin groups are named in `la-catrina.json`; the rear axle is one rigid node. Hood and trunk have portable service animations. Hydraulic road motion is supplied by the engine adapter and the shared physical solver.

Requires Python with NumPy, Pillow and SciPy. Regenerate with `python scripts/catrina_generate.py`; validate with `python scripts/catrina_audit.py`. Geometry and small vector cameos are original. Roof, hood and deck use rectified source ornament masks plus bounded source grain remapped to palette pigments. The side-spear scroll uses a source mask in a dedicated narrow UV field; its larger La Catrina and calavera cameos are original vectors. See `referencePaint` in the JSON for exact source SHA, sample coordinates and processing. Coachwork is authored in `scripts/catrina_art.py`; researched fittings in `scripts/catrina_hardware.py`; spring-pocket frame routing in `scripts/catrina_frame_pockets.py`; reference-paint rectification in `scripts/catrina_reference_paint.py`. These sources, `catrina_generate.py`, `baja427_generate.py`, `catrina_ao.py`, any matching geometry-bound cavity cache and the exact atlas under `docs/la-catrina/references/La-Catrina-Master.jpg` are required for regeneration. Original geometry follows the project license; no public redistribution license is asserted for the user-supplied artwork.
