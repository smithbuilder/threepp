# Restored Mercer data asset

November 9, 2026, Pacific Time. Author: SmithBuilder. This is an offline export of the original native Mercer art, not another simplified city kit. It retains all 11 building masses/four-sided facades, 15 distant context shells, roof/window/service detail, original branching trees, signs, road wear, markings, drains, street furniture and visible boundaries. The native code and source maps are unchanged.

`mercer-city.glb` is the frozen Unity-ready asset. `manifest.json` binds meshes, triangles, source snapshots, textures and the finite visual-ground reduction result. `materials.json` retains exact native linear RGB, roughness, metallic, normal strength, alpha cutoff, emission and original image identities. The original licensed surface records are copied in `photo-surfaces.json` and `source.json`. Original texture bytes are in `textures/`; the generated leaf cluster is the native seed-427 CPU image encoded as PNG. The eight `packed-*.png` files make GLB roughness visible in interchange tools; Unity's material binding uses the original roughness images from `textures/`.

The native city is 566,118 triangles. Only redundant flat visual ground tessellation is reduced: 232,320 to 50,163 triangles, leaving 383,961 city triangles. Every original sampled height is exact, the original nonflat half-metre curb cells and diagonal remain, and the largest RGB difference at original lattice vertices is 0.007742 in linear units against the 0.012 limit. Ground boundaries are stitched to avoid geometry T-junctions. This is finite sampled colour validation, not a universal bound between all samples. The authoritative simulation/collision surface is untouched. All non-ground geometry is copied without decimation.

The GLB has 26 meshes and 25 materials. `ground.asphalt` and `ground.paving` receive the moving car shadow. `static.*` meshes already carry native static baked shade and should not receive or cast another city-wide realtime shadow. Every mesh carries explicit COLOR_0 data. UV data is written as `(nativeU, 1-nativeV)` for glTF's image convention; the Unity importer restores `(nativeU, nativeV)`. Original photographic texture files keep their bytes. Generated GPU-row-order texture pixels are flipped once when encoding top-down PNG.

## Rebuild

1. `tools/cinder-city-export/build.cmd` builds the small CPU-only exporter against the existing native library. It includes the frozen four source headers first once this asset exists. It never creates a Canvas, renderer, window or physics world.
2. Sign that exporter with the established local signing helper. Run `tools/cinder-city-export/Run-NativeExport.ps1 -Output build/cinder-city-export/<new-output>`. The runner requires a valid signature, resource/process checks, the shared evaluation mutex, 2 GiB process job, pause markers, ten-second cooldown and a 180-second watchdog. Existing outputs are never overwritten.
3. Run `tools/cinder-city-export/package_city.py --input <native-output> --output <new-asset-folder>`. It requires NumPy and Pillow. It preserves exact geometry/material identities, freezes source/image hashes and validates all original ground-grid vertices against the reduced visual mesh. Use a new folder; preserve prior assets. `--full-control` retains all original ground triangles for comparison. The first full control is local at `build/cinder-city-export/full-control/mercer-city-full.glb`.
4. Run `tools/blender/cinder/restore_city.py` headlessly under the shared bounded tool guard. It validates the authoritative GLB through Blender 4.5, saves an editable local .blend and a JSON receipt, and leaves the GLB unchanged. The script accepts source-GLB and new-output-folder arguments after `--`.
5. Stage `mercer-city.glb` as `build/unity-assets/mercer-city/model.glb`; copy `textures/*` to `Unity/Assets/Resources/Cinder/CityRestored/`. Configure exact native material metadata during the Unity build. Do not draw the runtime city ground over this visual ground. Keep Unity Sim terrain for authoritative physics.

The first CPU export completed in 1.04 seconds at 207,507,456 bytes external peak working set. Offline conversion and Blender checks do not establish visual approval. Final Unity images/motion, performance measurements and independent native-relative review are still required.
